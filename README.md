# RiddhikaAR

🚀 RiddhikaAR is an interactive Augmented Reality (AR) web application designed to deliver immersive and engaging digital experiences directly through a web browser. The project combines modern web technologies with AR capabilities to create a seamless and responsive user experience across multiple devices.

## ✨ Features

* Interactive Augmented Reality experiences
* Responsive and mobile-friendly design
* Real-time 3D object visualization
* Clean and intuitive user interface
* Cross-platform browser compatibility
* Fast and lightweight performance

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* WebAR / AR Libraries
* GitHub Pages Deployment

## 🎯 Project Objective

The goal of this project is to explore and demonstrate the potential of Augmented Reality on the web by creating immersive experiences that are accessible without requiring users to install additional applications.
